### 필요한 기능를 정리한다.
1. 메인 메뉴 상태
- 메뉴 번호를 입력받는 기능 -> View
2. 동물 종류 등록 상태
- 동물 종류 입력하는 기능 -> View
3. 동물 종류 삭제 상태
- 동물 종류 입력하는 기능 -> View
- 저장된 동물 종류가 있는지 확인하는 기능 -> Repository
- 입력한 동물 종류를 삭제하는 기능 -> Repository
4. 동물 정보 등록 상태
- 저장된 동물 종류가 있는지 확인하는 기능 -> Repository
- 이름을 입력받는 기능 -> View
- 나이를 입력받는 기능 -> View
- 다리의 개수를 입력받는 기능  -> View
5. 동물 정보 전체 보기 상태
- 저장된 동물 종류가 있는지 확인하는 기능 -> Repository
- 전체 동물 정보를 가져오는 기능 -> Repository
- 전체 동물 정보를 출력하는 기능 -> View
- 총 동물수를 구하는 기능 -> Repository
6. 동물 이름 검색 상태
- 이름을 입력받는 기능 -> View
- 저장된 동물 이름이 있는지 확인하는 기능 -> Repository
- 저장된 동물 종류가 있는지 확인하는 기능 -> Repository
- 이름을 통해 동물 정보를 검색하는 기능  -> Repository
  검색된 동물의 정보를 출력하는 기능 -> View
7. 동물 정보 삭제 상태
- 저장된 동물 정보가 있는지 확인하는 기능 -> Repository
- 삭제할 동물 이름을 입력받는 기능 -> View
- 입력한 동물이 있는지 검사하는 기능 -> Repository
- 입력한 동물의 정보를 삭제하는 기능 -> Repository
8. 프로그램 종료
- 프로그램 종료
